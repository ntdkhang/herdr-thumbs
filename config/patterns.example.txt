# Extra match patterns, one Rust regex per line, loaded on top of the built-ins
# and the shipped defaults. Copy to the plugin config directory as
# patterns.txt:
#
#   cp config/patterns.example.txt "$(herdr plugin config-dir sd2k.thumbs)/patterns.txt"
#
# A (?P<match>...) group or the first capture group becomes the copied text;
# without either, the whole match is used. Custom patterns take priority over
# the built-in ones when they start at the same column.

# Jira-style issue keys
# [A-Z][A-Z0-9]+-[0-9]+

# Kubernetes pod names in kubectl output
# [a-z0-9-]+-[a-z0-9]{8,10}-[a-z0-9]{5}

# Grafana dashboard UIDs from a URL
# /d/(?P<match>[a-zA-Z0-9_-]{8,})

# npm/cargo versions
# v?[0-9]+\.[0-9]+\.[0-9]+(-[a-z0-9.]+)?
